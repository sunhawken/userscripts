# Userscripts

A collection of Tampermonkey/Violentmonkey userscripts.

- **nexus-mods-continuous-scroll.user.js** — Infinite scroll for Nexus Mods listing/search pages (both the classic `www.nexusmods.com` and new `next.nexusmods.com` frontends), plus filter memory (checkbox and URL-parameter filters), viewed/new-mod tracking, a Track/Untrack toggle on grid cards, and a "show my downloaded mods" view built from your download history.
- **AutoPager.user.js** — Multi-site seamless auto-pager / infinite scroll (forums, search engines, manga readers, and more), with a customizable rule system.
- **f95zone-grid.user.js** — Adds a grid/card view with infinite scroll to F95Zone forum thread lists.
- **VAM-Hub-Grid-AutoPager.user.js** — Grid/card view, infinite scroll, and thumbnail controls for the Virt-A-Mate Hub.

## Installation

Install [Tampermonkey](https://www.tampermonkey.net/) (or a similar userscript manager), then open any `.user.js` file above and import it (or use Tampermonkey's "Import from file").
